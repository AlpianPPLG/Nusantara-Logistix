# PANDUAN MENGGUNAKAN FILE CODE-TO-DIAGRAM DI DRAW.IO

Sesuai permintaan Anda untuk mendesain dengan **rapih, tidak tumpang tindih, dan jelas dibaca**, metode *Code-to-Diagram* adalah solusi standar industri yang paling tepat. Draw.io memiliki fitur pintar untuk merender teks kode (Mermaid / PlantUML) menjadi diagram yang otomatis tertata rapi.

## Langkah-langkah Penggunaan di Draw.io:

1. Buka situs [Draw.io (app.diagrams.net)](https://app.diagrams.net/) atau buka aplikasi Draw.io di komputer Anda.
2. Buat diagram baru (Blank Diagram).
3. Di menu bagian atas, klik **Arrange**.
4. Pilih **Insert** -> lalu klik **Advanced** -> pilih **Mermaid...** (Untuk file flowchart) ATAU **PlantUML...** (Untuk file UML).
5. Buka salah satu file teks `.txt` yang telah saya buat (misal: `1_flowchart_keseluruhan_drawio.txt`).
6. **Copy (Salin)** seluruh teks kode yang ada di dalamnya.
7. **Paste (Tempel)** ke dalam kotak teks yang muncul di Draw.io, lalu klik tombol **Insert**.
8. Secara otomatis diagram yang sangat rapi dan tidak tumpang tindih akan terbuat!
9. Anda kemudian dapat menyimpannya (Save As) menjadi file `.drawio` murni jika diinginkan.

*Catatan: Semua file modul Flowchart menggunakan bahasa **Mermaid**, sedangkan semua file modul UML (Use Case, Activity, Class, Sequence) menggunakan bahasa **PlantUML**.*
